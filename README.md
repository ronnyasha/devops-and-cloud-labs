## Зміст та деталі робіт

### Лабораторна робота №1
**Тема:** Віртуалізація. Гіпервізори.  
**Мета:** Ознайомитися з поняттям віртуалізації та її видами. Налаштувати ВМ Ubuntu у середовищі Oracle VirtualBox.  
**Ключові кроки:**
* Створення та конфігурація ВМ з ОС Ubuntu в VirtualBox.
* Налаштування SSH-сервера (`openssh-server`), зміна дефолтного порту на `2222`.
* Прокидання портів (Port Forwarding) у VirtualBox.
* Встановлення `virtualbox-guest-dkms` та `virtualbox-guest-utils` для роботи спільних папок (Shared Folders) та додавання користувача до групи `vboxsf`.


### Лабораторна робота №2
**Тема:** Віртуалізація. Vagrant.  
**Мета:** Засвоїти автоматизоване конфігурування ВМ за допомогою Vagrant.  
**Ключові кроки:**
* Ознайомлення з провайдерами та операторами Vagrant (Shell, Ansible, Chef/Puppet, Docker).
* Ініціалізація та підключення до ВМ через `vagrant up` та `vagrant ssh`.
* Налаштування автоматичного автоматичного розгортання (Provisioning) за допомогою `setup.sh`.
* Використання команд `vagrant reload --provision`.
* Порівняння роботи з VirtualBox через GUI та Vagrant CLI.


### Лабораторна робота №3
**Тема:** Контейнеризація. Docker.  
**Мета:** Вивчити основи Docker, створення власних образів, роботу з мережами та Docker Compose.  
**Ключові кроки:**
* Створення кастомних Docker-образів на базі `alpine nginx`.
* Опанування команд `docker run`, `ps`, `stop`, `images`.
* Налаштування кастомного прокидання портів та заміна контенту сторінки через `ADD`/`COPY`/`VOLUME`.
* Побудова кастомного `docker-compose.yml` для зв'язування декількох контейнерів.


### Лабораторна робота №4
**Тема:** Хмарні обчислення.  
**Мета:** Вивчення концепції хмарних обчислень (IaaS) на прикладі Amazon Web Services (AWS).  
**Ключові кроки:**
* Створення ключа доступу `.pem` та налаштування Security Group (відкриття 80 та 22 портів) в AWS EC2.
* Створення інстансу Ubuntu в хмарі AWS.
* Розгортання Docker-контейнера з вебзастосунком на хмарному інстансі.


### Лабораторна робота №5
**Тема:** Безперервне розроблення та розгортання (CI/CD).  
**Мета:** Побудова автоматизованого CI/CD пайплайну з доставкою змін у хмару AWS при коміті в GitHub.  
**Ключові кроки:**
* Налаштування automated build & push пайплайну через **GitHub Actions** (`main.yml`) до Docker Hub.
* Запуск сервісу **Watchtower** на EC2-інстансі для автоматичного відстеження та оновлення запущенного контейнера при появі нового образу.


### Лабораторна робота №6
**Тема:** Інфраструктура як код (IaC). Terraform.  
**Мета:** Автоматизація створення хмарної інфраструктури в AWS за допомогою Terraform.  
**Ключові кроки:**
* Конфігурування IAM ключів доступу AWS (`AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`).
* Написання конфігурації `main.tf` для створення Security Group та EC2 інстансу.
* Виконання циклу команд IaC: `terraform init` -> `terraform plan` -> `terraform apply`.


### Лабораторна робота №7
**Тема:** Подійно-орієнтована архітектура (EDA). RabbitMQ.  
**Мета:** Опанування брокера повідомлень RabbitMQ та протоколу AMQP для асинхронного обміну даними.  
**Ключові кроки:**
* Розгортання RabbitMQ з Web Management Interface у Docker.
* Створення двох Telegram-ботів на Python: **Producer** (надсилає повідомлення в чергу) та **Consumer** (зчитує з черги та відправляє користувачу).
* Об'єднання сервісів в єдину інфраструктуру за допомогою `docker-compose.yml`.


### Лабораторна робота №8
**Тема:** Моніторинг систем. Логи. Стек EFK.  
**Мета:** Побудова централізованого стеку збору та аналізу логів (Elasticsearch, Fluentd, Kibana).  
**Ключові кроки:**
* Розгортання Docker-стеку EFK.
* Написання Python-застосунку (`app.py`), що генерує структуровані JSON-логи (INFO, WARNING, ERROR).
* Налаштування Index Patterns у Kibana, фільтрація та візуалізація подій у розділі *Discover*.


### Лабораторна робота №9
**Тема:** Моніторинг систем. Метрики. Prometheus & Grafana.  
**Мета:** Налаштування збору числових метричних даних та створення моніторинг-дашбордів.  
**Ключові кроки:**
* Інтеграція бібліотеки `prometheus_client` у Python-застосунок для експорту метрик (HTTP endpoint `/metrics`).
* Налаштування збирача метрик `prometheus.yml`.
* Візуалізація даних у **Grafana**, створення інтерактивних графіків для відстеження стану системи.
